# Security and Privacy

Current demo records are synthetic. The seeded evaluation runner contacts no external model. Environment files, local state, build output, caches, editor state and operating-system files are ignored by Git. Do not place credentials or real sensitive records in fixtures or committed configuration.

Browser localStorage and client-side role checks do not provide production security, authorization, encryption, tenant isolation or tamper-resistant audit. Production needs server-side identity and authorization, tenant-scoped persistence, secret management, evidence access control, retention rules, audit integrity and security review. Framework summaries require source review where indicated by metadata.
