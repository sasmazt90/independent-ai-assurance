# Demo Data

All names and records are illustrative synthetic data. Five AI systems, four findings, framework metadata, normalized controls, recent monitoring events and release states are centralized in `src/data/demo.ts` or the page fixtures. No actual organization, patient, customer, model or operational trace is represented.

Repository state for findings and system records persists locally in the browser under the `iaa:` prefix. Clear local site data to reset the demo. Evaluation runs are deterministic workflow simulations and explicitly do not call a model.
