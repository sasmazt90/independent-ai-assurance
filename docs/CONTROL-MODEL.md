# Control Model

```text
Framework Version → Requirement → Master Control → Evaluation Procedure → Test → Evidence → Result → Finding
```

Framework requirements are versioned references. Master controls normalize shared assurance objectives. Many framework requirements may map to one control; mappings carry their source version and validation status. Evaluation procedures define repeatable methods and criteria. Each test run records system version, evaluator type/version, sample context and artifacts. Results are PASS, FAIL, REVIEW or NOT_APPLICABLE. Findings are created from material failure or review outcomes and retain provenance to the test and evidence.

Human review is explicit per control as AUTOMATED, HUMAN_REQUIRED or HYBRID. Automated outcomes alone do not establish compliance.
