# Control Model

Controls are typed `MasterControl` records with stable IDs, domain, objective, risk addressed, applicability, evaluation method, automation capability, human-review requirement, criteria, status and versions. The demo library covers reliability, security, fairness, privacy, human oversight, governance, data governance and lifecycle monitoring.

The UI reads controls and versioned relationships from seed records. Applicability metadata exists, but the current list view does not filter controls by selected system type. Control editing and publication workflows are not implemented. The broader requested domain taxonomy is incomplete.
