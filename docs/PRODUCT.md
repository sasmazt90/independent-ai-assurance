# Product

**Independent AI Assurance** — Independent assurance for AI systems. We don't build AI. We verify it.

This visual MVP organizes AI systems, runs deterministic demo evaluations, reviews findings and evidence, monitors seeded changes, displays explicit framework mappings and computes demo release-gate decisions. It provides English, German and Turkish message catalogs, a compact enterprise workspace, organization switching and light/dark theme presentation.

It is not a certification platform or production security boundary. Evaluations use seeded data, flagged framework summaries need authoritative review, persistence is browser-specific, and real evaluation execution, framework publishing, durable release overrides and complete locale coverage remain incomplete.
