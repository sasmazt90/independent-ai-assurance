# Independent AI Assurance

Independent assurance for AI systems. We don't build AI. We verify it.

A multilingual local MVP for registering, evaluating, monitoring and documenting AI systems operated by other organizations. Demo records and evaluation outcomes are synthetic and deterministic; the app does not contact external AI systems.

## Run locally

```sh
npm install
npm run dev
```

## Validate

```sh
npm run typecheck
npm run lint
npm run test
npm run build
```

See `docs/` for product, architecture, assurance methodology, control model, framework mapping, scoring, security and demo data notes. Assessment results are not legal advice, regulatory approval or certification.
